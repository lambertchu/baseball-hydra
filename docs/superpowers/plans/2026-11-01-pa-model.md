# Learned PA Projection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Marcel PA with a PA model learned from FanGraphs batting history, and add an all-players view to the public benchmark so PA misses count.

**Architecture:** `src/eval/pa_projection.py` gains a learned model that is fit at call time on `data/raw/batting_YYYY.parquet` (every hitter, so a missing next season is a 0-PA label). One dispatcher, `project_next_season_pa`, replaces direct Marcel calls and takes a label cutoff so the benchmark cannot leak. The benchmark gains a second scoring view over every projected player, with missed time counted as 0.

**Tech Stack:** Python, pandas, scikit-learn (already a dependency: `LinearRegression`, `HistGradientBoostingRegressor`), PyYAML.

**Spec:** `docs/lambda/intent/2026-11-01-pa-model.md`

## Global Constraints

- Two PRs, each off the latest `main`: PR 1 `claude/learned-pa-model` (Tasks 1-3), PR 2 `claude/benchmark-all-players` (Tasks 4-5).
- No new tests or docs (owner rule). Verification uses a scratch backtest plus the existing suite: `uv run pytest tests/ -q`.
- No public projections in the pipeline. No change to rate models or the ROS pipeline.
- Do not regenerate `data/projections/projections_mtl_2026.csv`. Do not write to `data/reports/benchmark/` (use `--output-dir` in the scratchpad).
- 2020 (60 games) scales to a 162-game pace as a feature year and is never a label year.
- Benchmark year T trains the PA model on label years ≤ T−1 only.
- Success: pooled 2022-2026 PA RMSE ≤ 165 (Marcel 190), mean bias within ±25 PA; 2026 count skill on all 240 projected players ≥ 17% (Marcel 10.9%).

## Review Focus

1. **Label year 2020:** a 60-game season must never be a label. Training rows with label year 2020 are dropped; 2020 features are scaled ×162/60.
2. **Zero-PA next seasons:** a player absent from `batting_{Y+1}` is a 0-PA label (training) and a 0 actual (all-players view), never dropped.
3. **File glob:** `data/raw` also holds `batting_week_YYYY.parquet`. The history loader reads only `batting_\d{4}.parquet`.
4. **Leakage:** `data/raw` already holds the eval year's file. The fit must filter label year ≤ `max_label_year`; prediction features use seasons ≤ the row's season only.
5. **ID types:** `idfg` is int in merged data and may be float in parquet. Both sides cast to int before joins.

Each line gets a check in Task 3 (PR 1) or Task 5 (PR 2).

- Modify: `configs/data.yaml` (new `pa_model` block after `season_games`)

**Interfaces:**
- Produces:
  - `load_batting_history(raw_dir: str | Path) -> pd.DataFrame` with columns `idfg, season, pa, g, age, war, wrc_plus`, one row per (idfg, season).
  - `pa_features(keys: pd.DataFrame, history: pd.DataFrame, season_games: dict[int, int]) -> pd.DataFrame` with columns `pa_y1, pa_y2, pa_y3, g_y1, war_y1, wrc_plus_y1, age, age_sq`, index aligned to `keys` (`keys` needs `idfg`, `season`).
  - `fit_pa_model(history: pd.DataFrame, max_label_year: int, season_games: dict[int, int], cfg: dict, seed: int) -> object` returning a fitted estimator with `.predict`.
  - `project_next_season_pa(df: pd.DataFrame, data_config: dict, max_label_year: int) -> pd.Series` indexed like `df`.

- [ ] **Step 1: Add the config block**

```yaml
pa_model:
  method: learned        # learned | marcel
  estimator: ols         # ols | gbm, set by the Task 3 backtest
  min_pa_train: 200      # PA in season Y required for a training row
  gbm: {max_iter: 200, learning_rate: 0.05, max_depth: 3, min_samples_leaf: 40}
```

- [ ] **Step 2: Implement the four functions**

Feature rules: `pa`, `g`, `war` scale by `162 / season_games[year]` for short seasons; `wrc_plus` does not scale. A prior season inside the history range with no row is 0; a season before the first history year is NaN. Training rows: `pa_Y ≥ min_pa_train`, `Y+1 ≤ max_label_year`, `Y+1` not a short season, `Y−2 ≥` first history year. Label: unscaled PA in `Y+1`, 0 if absent. `ols` → `LinearRegression()`; `gbm` → `HistGradientBoostingRegressor(**cfg["gbm"], random_state=seed)`. Predictions clip to `[0, 750]`. `method: marcel` returns `project_pa(df, season_games)`.

- [ ] **Step 3: Smoke-check**

Run: `uv run python -c "import yaml,pandas as pd; from src.eval.pa_projection import project_next_season_pa as f; c=yaml.safe_load(open('configs/data.yaml')); d=pd.read_parquet('data/merged_batter_data.parquet'); d=d[(d.season==2025)&(d.pa>=300)]; s=f(d,c,2025); print(len(s), s.isna().sum(), round(s.mean()))"`
Expected: about 243 rows, 0 NaN, mean near 425 (2026 actual mean for this group).
